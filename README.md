# ZAMBRIA

## O Insólito Presente

Blog pessoal — curiosidades, ciências, arqueologia antiga, OVNIs, sobrenatural e mistérios.

Tom editorial: sério, sombrio, adulto formal, sarcástico às vezes.

Estrutura mínima de cada post:
- Suspense
- Comentário breve do agente em momentos de interesse (sem opinião, apenas reação)
- Fontes consultadas sempre no final

Calendário: 2 posts por dia.

Hospedado com GitHub Pages em https://zambria.github.io

Estrutura:
- `/index.html` — página principal com abas à esquerda
- `/style.css` — design preto com texto branco e vermelho neon sutil
- `/topics.json` — catálogo de tópicos do blog
- `/estado-publicador.json` — controle diário de publicação
- `/posts/` — artigos publicados
- `/content/` — páginas estáticas
