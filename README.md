# ZAMBRIA

## o insólito presente

Blog pessoal — curiosidades, ciências, arqueologia antiga, OVNIs, sobrenatural e mistérios.

Hospedado com GitHub Pages em https://zambria.github.io

Estrutura:

- `/drafts` — rascunhos de artigos em andamento
- `/review` — artigos em revisão antes de publicar
- `/_posts` — artigos publicados (Jekyll)
- `/content` — páginas e conteúdos estáticos
- `topics.json` — catálogo de tópicos do blog

Modo piloto: 1 post por dia.
